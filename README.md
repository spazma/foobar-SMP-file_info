# 📄 file_info_panel — dynamiczny panel informacji o pliku dla foobar2000 (SMP 1.6.1)

Lekki, czytelny i w pełni dynamiczny panel wyświetlający szczegółowe informacje o aktualnie odtwarzanym pliku audio.  
Zaprojektowany z myślą o przejrzystości, minimalizmie i praktycznym układzie danych.

---

## ✨ Funkcje

- **Automatyczne ukrywanie pustych pól**  
  Panel wyświetla tylko te informacje, które faktycznie istnieją w tagach pliku.

- **Przejrzysty układ sekcji**  
  - Audio (bitrate, samplerate, channels, codec)  
  - File (nazwa, folder, rozmiar, daty)  
  - ReplayGain (gain, peak, ostrzeżenia)  
  - Playback (czas, licznik odtworzeń, ostatnie odtworzenie)

- **Obsługa długich ścieżek**  
  - automatyczne zawijanie  
  - opcjonalne skracanie  

- **Współpraca z foobar2000 i SMP 1.6.1**  
  - pełna kompatybilność  
  - brak zależności od zewnętrznych bibliotek

- **Estetyczny, minimalistyczny wygląd**  
  - Segoe UI  
  - logiczne odstępy  
  - czytelne kolory i wyrównanie
  - scrollowanie myszą (pasek scrola po prawej)

## 📁 Instalacja

1. Utwórz nowy panel Spider Monkey Panel  
2. Wklej zawartość `file_info_panel.js`  
3. Zapisz i odśwież panel  
4. Gotowe — panel automatycznie dostosuje się do odtwarzanego pliku
